ANDROID APK / DIRECT INSTALL

Installer sans Google Play Store

Install without Google Play Store

Lorsqu'un APK est disponible, vous le téléchargez depuis Hailite Labs. Il devient une vraie application Android avec sa propre icône et ne nécessite pas d'ouvrir le navigateur pour être lancé.

Once an APK is available, download it from Hailite Labs. It installs as a real Android app with its own icon; you won't need a browser to launch it.

01

Télécharger

Download

Sur votre téléphone Android, touchez « Télécharger APK » dans la fiche d'une application publiée.

On an Android phone, tap “Download APK” on a published app page.

02

Autoriser et confirmer

Allow and confirm

Ouvrez le fichier téléchargé. Si Android le demande, autorisez cette source à installer l'application, puis confirmez. Ne contournez pas les alertes de sécurité.

Open the downloaded file. If prompted, allow installation from this source and confirm. Do not bypass security warnings.

03

Ouvrir l'application

Open the app

Retrouvez l'icône parmi vos applications et placez-la sur l'écran d'accueil si vous le souhaitez.

Find its icon among your apps and add it to your home screen if you wish.

Conseils de sécuritéSecurity tips

Téléchargez uniquement depuis le site officiel. Les versions seront signées et accompagnées de leur numéro de version et empreinte SHA-256. Android exige toujours votre confirmation pour installer un APK; un site Web ne peut pas l'installer automatiquement. Les APK ne fonctionnent pas sur iPhone.

Only download from the official site. Releases will be signed and show their version and SHA-256 checksum. Android still requires confirmation to install an APK; websites cannot install it silently. APKs do not work on iPhone.
